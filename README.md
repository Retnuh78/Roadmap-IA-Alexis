# Roadmap-IA-Alexis

Roadmap IA pragmatique sur 12 semaines, à destination d'un étudiant marketing digital de 21 ans qui connaît déjà ChatGPT et Gemini et veut intégrer Claude + les agents IA sans se disperser.

## Livrable

- **[`index.html`](./index.html)** — page web standalone, autoportante, mobile-first.

Ouvrir simplement `index.html` dans n'importe quel navigateur moderne (Chrome, Safari, Firefox). Aucun build, aucune dépendance locale.

## Contenu

1. **Hero** — posture : arbitrer, pas accumuler.
2. **La stack à 4 piliers** — Claude Pro (Opus 4.7), ChatGPT Plus (GPT Image 2), Gemini AI Pro (Nano Banana 2), NotebookLM. Total ~62 $/mois.
3. **Les 5 phases** — fondations Claude → création visuelle multi-modèles → veille & savoir → automatisation légère → agents avancés (Computer Use, OpenClaw).
4. **Pièges à éviter** — 5 erreurs typiques.
5. **Lecture stratégique** — citation finale.

## Stack technique

- HTML + CSS natif (pas de Tailwind CDN, pas de JS framework).
- Google Fonts : Inter, JetBrains Mono.
- Palette Claude Design (light, sobre).
- Poids : ~27 KB.
