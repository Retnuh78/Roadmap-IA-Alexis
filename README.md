# Roadmap-IA-Alexis

Mode d'emploi pratique pour démarrer Claude et Claude Desktop sur Mac, à destination d'un étudiant marketing digital de 21 ans déjà familier de ChatGPT et Gemini.

## Livrable

- **[`index.html`](./index.html)** — guide standalone, autoportant, mobile-first.

Ouvrir simplement `index.html` dans n'importe quel navigateur. Aucun build, aucune dépendance locale.

## Contenu

1. **Étape 1 — Installer & s'abonner** : Claude Pro, Claude Desktop sur Mac, premier login.
2. **Étape 2 — Comprendre l'écosystème** : Claude.ai, Claude Desktop, Cowork, Claude Code — qui fait quoi.
3. **Étape 3 — Configurer ton Claude** : Compétences, Connecteurs, Plugins, Instructions personnalisées (compte / Project / Cowork / `CLAUDE.md`).
4. **Étape 4 — Agent vs chatbot, premier Cowork** : la marche cognitive à passer + tutoriel Cowork pas-à-pas.
5. **Étape 5 — Mon workflow** : tableau d'arbitrage entre Claude, GPT Image, Nano Banana, Gemini, NotebookLM, Grok, Claude Code.
6. **Bonnes pratiques & pièges** : modèles, quotas, prompt, hygiène données, vérification, sauvegarde, 5 prompts marketing prêts à copier.

## Stack technique

- HTML + CSS natif (pas de framework JS).
- Google Fonts : Inter, JetBrains Mono.
- Palette Claude Design (light, sobre).
