Étape 1

Installer & s'abonner

›

15 minutes chrono. Tu auras Claude prêt à l'emploi sur ton Mac et dans ton navigateur.

1.1 — Prendre l'abonnement Claude Pro

  1. Va sur claude.ai (ou claude.com, c'est le même service) et crée un compte (Google ou e-mail).
  2. Settings → Plans & Billing → choisis Pro.
  3. Tarif : 20 $/mois en mensuel, ou 17 $/mois si tu prends à l'année (~36 $ d'économisés sur 12 mois).
  4. Le plan Pro débloque : modèle Opus 4.7, Projects, Cowork, plus de Skills, plus de Connecteurs, quotas confortables.
Astuce coût : tu n'as pas besoin de garder ChatGPT Plus en parallèle. Pour les visuels avec texte (GPT Image 2), le plan gratuit ChatGPT suffit largement à un usage étudiant. Pour la veille temps réel via Grok, idem : version gratuite sur grok.com ou inclus dans X si tu y es. Cible réaliste : ~17-20 $/mois pour Claude Pro, le reste en gratuit.

1.2 — Installer Claude Desktop sur Mac

  1. Va sur claude.com/download (ou claude.ai/download) et télécharge la version macOS.
  2. Ouvre le .dmg, glisse Claude.app dans Applications.
  3. Lance Claude depuis Spotlight (⌘ + Espace, tape "Claude").
  4. Connecte-toi avec le même compte que claude.ai. Tout est synchronisé (conversations, Projects, Skills).
  5. Autorise les notifications et l'accès au système de fichiers quand l'app le demande — c'est ce qui rendra Cowork fonctionnel plus tard.

1.3 — Tour rapide de l'interface

  • Sidebar gauche : tes conversations récentes et tes Projects.
  • Sélecteur de modèle (en haut de la zone de chat) : Sonnet par défaut, bascule sur Opus pour les tâches complexes.
  • Bouton "Cowork" en haut de l'app : c'est là que tu actives le mode agent (cf. étape 4).
  • Bouton + ou icône trombone dans la barre de saisie : joindre fichier, photo, ou lancer un Connecteur.
  • Settings (en bas à gauche, ton avatar) : profil, modèles, Connecteurs, Compétences, Plugins, Custom Instructions.

1.4 — Tes 30 premières minutes

Si tu ne sais pas par où commencer, suis ce planning. Tu auras un Claude opérationnel et un premier Cowork qui marche en une demi-heure.

  1. 0-5 min — Installer. Télécharge Claude Desktop, ouvre Pro dans Settings, lance l'app.
  2. 5-10 min — Crée ton about-me.md. Un fichier texte de 10-20 lignes : qui tu es, ton rôle (étudiant marketing, 21 ans, MacBook), comment tu communiques (direct, tutoiement, anti-yes-man), un exemple court d'écriture qui te ressemble.
  3. 10-15 min — Premier Cowork. Crée un dossier de travail (cf. étape 4), sélectionne-le dans Cowork, demande à Claude : « Lis le fichier about-me.md. Résume-moi qui je suis en 3 lignes. »
  4. 15-20 min — Teste un Plugin. Va sur claude.com/plugins, installe le plugin Marketing, retourne dans le chat, tape / pour voir les commandes disponibles.
  5. 20-25 min — Connecte un outil. Settings → Connecteurs → ajoute Google Drive ou Gmail selon ce que tu utilises le plus.
  6. 25-30 min — Essaie Claude dans Excel. Ouvre un classeur (cours, suivi de stage), demande « Résume chaque onglet en 2 phrases. » (cf. encart Excel plus bas).
Étape 2

Comprendre l'écosystème

›

Quatre "Claude" différents, qui partagent ton compte et tes données. Sache lequel utiliser quand.

Web

Claude.ai

L'interface dans le navigateur. Tu y as accès depuis n'importe quel device, y compris ton smartphone.

Utilise-le pour : tester rapidement, partager une conversation, accéder depuis le téléphone.

Desktop

Claude Desktop (Mac)

L'app native macOS. Mêmes conversations que claude.ai, plus l'accès au système de fichiers, aux Connecteurs locaux et à Cowork.

Utilise-la pour : ton usage quotidien sur Mac. C'est le centre de gravité.

Agent

Cowork

Mode agentic dans Claude Desktop. Claude lit, modifie et crée des fichiers dans un dossier que tu lui donnes, étape par étape, avec ton accord.

Utilise-le quand : tu veux un livrable concret (rapport, persona, plan), pas juste une réponse.

CLI · Dev

Claude Code

Outil en ligne de commande pour les tâches de développement. S'installe via npm. Lit/écrit ton code, lance des commandes git, exécute des tests.

Utilise-le pour : coder un site, automatiser un script, gérer un repo. Pas pour rédiger.

À retenir : Cowork n'est pas une app séparée. C'est un mode dans Claude Desktop. Tu n'as rien à installer en plus.
Étape 3

Configurer ton Claude

›

Quatre leviers à connaître : Compétences, Connecteurs et Plugins (les 3 onglets du Répertoire), plus les Instructions personnalisées qui se règlent ailleurs.

3.1 — Compétences (Skills)

Une Compétence est un mini-mode d'emploi qu'on donne à Claude pour qu'il fasse une tâche bien précise et de façon répétable. Concrètement c'est un dossier avec un fichier SKILL.md qui décrit la marche à suivre, plus parfois des scripts. Claude la déclenche tout seul quand le contexte le justifie.

Exemples utiles pour toi :

  • brief-créa : tu décris le client + l'objectif, Claude pond un brief créa structuré.
  • persona : tu donnes un produit, Claude génère un persona marketing complet.
  • audit-landing : tu colles l'URL ou les contenus, Claude rend un audit UX/copy.

Installer une Compétence

  1. Dans Claude Desktop, ouvre le Répertoire (icône à gauche ou via Settings).
  2. Onglet Compétences.
  3. Trouve une Compétence pré-faite par Anthropic ou un partenaire → bouton +.

Créer une Compétence perso

Le plus simple : demande à Claude lui-même. Prompt type : « Crée-moi une Compétence Claude qui fait X. Génère le SKILL.md selon la spec officielle. » Tu obtiens un fichier que tu déposes dans le bon dossier (Claude Desktop te guide pour l'emplacement).

3.2 — Connecteurs

Un Connecteur donne à Claude l'accès à un service ou une donnée. Techniquement c'est un serveur MCP (Model Context Protocol). En pratique tu cliques, tu autorises, ça marche.

Connecteurs prioritaires pour toi :

  • Filesystem — accès aux fichiers de ton Mac. Indispensable pour Cowork.
  • Google Drive — Claude lit/écrit dans tes Docs et Sheets.
  • Gmail — Claude rédige tes mails de candidature, prépare des relances.
  • Calendar — Claude lit ton agenda pour planifier autour.
  • Figma (plus tard) — pour récupérer des maquettes en contexte.

Ajouter un Connecteur

  1. Répertoire → onglet Connecteurs.
  2. Filtre Anthropic & Partenaires pour les officiels.
  3. Bouton + sur le connecteur voulu.
  4. Claude ouvre une fenêtre OAuth (Google / Microsoft / etc.) → tu autorises uniquement les scopes nécessaires.
  5. Le connecteur apparaît dans la liste active. Tu peux désactiver à tout moment.

Connecteurs tiers : tout ce qui n'est pas estampillé "Anthropic" est un MCP server tiers. Lis ce qu'il fait avant d'autoriser. En cas de doute : ne l'installe pas.

3.3 — Plugins

Un Plugin est un bundle métier de compétences et de commandes pré-configurées. Tu installes le plugin "Marketing" et Claude reçoit d'un coup un paquet de Compétences et de slash-commands liées à ce métier (par exemple /persona, /brief-créa, /audit-landing).

Les 11 plugins officiels couvrent : Ventes, Marketing, Juridique, Finance, Données, Produit, Support, etc. Pour toi, le bon départ c'est Marketing.

Installer un Plugin

  1. Va sur claude.com/plugins (ou Répertoire → onglet Plugins dans Claude Desktop).
  2. Parcours la liste, choisis-en un (Marketing pour démarrer).
  3. Clique Installer.
  4. Retourne dans le chat, tape / dans la barre de saisie : tu vois la liste des commandes que ce plugin a ajoutées.
Plugins vs Compétences vs Connecteurs :
  • Compétence = une recette unique (un SKILL.md).
  • Plugin = un pack thématique de compétences + commandes (Marketing = N recettes d'un coup).
  • Connecteur = un accès à un service ou une donnée (Drive, Gmail, Slack, Notion, Figma…).

3.4 — Instructions personnalisées : trois endroits à connaître

C'est le levier qui sort Claude du ton IA générique. Trois emplacements, trois portées différentes.

(a) Au niveau du compte — Claude.ai

Settings → Profile → Personalisation / Custom Instructions. Ce que tu écris là s'applique à toutes tes conversations, partout (web et Desktop).

À mettre : qui tu es (étudiant marketing digital, 21 ans), comment tu veux que Claude te parle (tutoiement, style direct, pas de yes-man), domaines qui t'intéressent.

(b) Au niveau du Project — Claude.ai & Desktop

Un Project = un dossier de conversations + un système de prompt + des fichiers de contexte. Le system prompt du Project surclasse les instructions du compte sur ce projet.

Cas d'usage :

  • Project "Études marketing" : ton style de devoir, format APA pour les sources, etc.
  • Project "Stage [nom de la boîte]" : nom du client, ton de marque, contexte produit.
  • Project "Veille perso" : sources préférées, format de fiche de lecture.

(c) Pour Cowork — dans Claude Desktop

Cowork hérite du Project actif. Tu n'as donc qu'un seul endroit où penser ton contexte : le Project. Les fichiers que tu déposes dans le Project (PDF, briefs, charte de marque) sont visibles par Cowork.

(d) Pour Claude Code — fichiers CLAUDE.md

Claude Code lit deux fichiers de contexte au démarrage :

  • ./CLAUDE.md — à la racine du projet sur lequel tu travailles. Spécifique au repo.
  • ~/.claude/CLAUDE.md — global. Tes préférences personnelles qui s'appliquent à tous tes projets de code.

Le fichier projet complète le fichier global. Mets dans le global tes conventions perso ("anti-yes-man", "commenter plutôt qu'optimiser") et dans le projet le contexte du repo (stack, conventions, scripts à connaître).

Étape 4

Agent vs chatbot — premier Cowork

›

La marche cognitive la plus rentable à passer en 2026 : comprendre ce qui change quand l'IA agit au lieu de juste répondre.

Chatbot

Il répond

Tu poses une question, il génère du texte. À toi ensuite de copier, coller, mettre en forme, sauver. Tu fais le travail final.

Exemple : "Donne-moi une trame de persona marketing." → Claude liste les sections, tu rédiges.

Agent

Il agit

Tu donnes une mission, il enchaîne les étapes : il lit des fichiers, en crée d'autres, exécute des commandes, te demande validation aux moments-clés. Tu superviseS.

Exemple : "Dans ce dossier, génère le persona dans persona.md à partir du brief." → Cowork le fait, tu relis.

Configure Cowork une bonne fois pour toutes

Avec Cowork, le jeu se joue avec des fichiers texte, pas avec des prompts qui s'évaporent à chaque conversation. Prends ce que tu sais (ton style, tes règles, tes meilleurs exemples) et mets-le dans des fichiers .md. Claude les relit à chaque tâche.

(a) Crée la structure de dossier de travail

Sur ton Mac, crée un dossier ~/Claude-Cowork/ avec cette arborescence — tu la garderas pour des années :

~/Claude-Cowork/
├── À-PROPOS-DE-MOI/
│   └── about-me.md            # qui tu es + tes règles d'écriture
├── MODÈLES/
│   ├── persona-template.md    # tes templates réutilisables
│   ├── brief-créa-template.md
│   └── audit-landing-template.md
└── CLAUDE-OUTPUTS/             # ici Claude dépose tous ses livrables
    └── (vide au début)

(b) Le fichier about-me.md : ton ADN

C'est le fichier le plus important. Tu le rédiges une fois, Claude s'y réfère à chaque tâche. Modèle de départ :

# À propos de moi

Je m'appelle [PRÉNOM]. J'ai 21 ans, je suis étudiant en marketing
digital. Je travaille sur Mac.

## Ma posture
- Direct, sans jargon ni langue de bois.
- Anti-yes-man : si une idée est mauvaise, dis-le.
- Je préfère 3 propositions argumentées qu'une seule "parfaite".

## Mon style d'écriture
- Phrases courtes, une idée par phrase.
- Pas d'emojis sauf si je le demande.
- Pas de "🚀", pas de "thread", pas de "game-changer".

## Exemple de ce que j'aime écrire
[colle ici un de tes meilleurs posts ou paragraphes]

## Mes domaines d'intérêt actuels
Marketing digital, social media, créa, analyse de campagnes,
data marketing.

(c) Les instructions globales Cowork — à coller une fois

Va dans Settings → Cowork → Instructions globales et colle ce bloc. Il s'applique à toutes tes sessions Cowork :

- Lis À-PROPOS-DE-MOI/about-me.md avant chaque tâche.
- Lis les fichiers du dossier MODÈLES/ correspondants à la tâche
  si pertinent.
- Étudie TOUJOURS la structure du projet avant de créer du contenu.
- Sauvegarde tous tes livrables dans CLAUDE-OUTPUTS/.
- Pose-moi des questions de clarification si l'objectif est flou
  (au lieu d'inventer).
- N'invente pas. Livre le travail.
Pourquoi c'est puissant : ces 6 lignes transforment Cowork en un assistant qui te connaît et qui sauve son travail au bon endroit. Tu poses ces règles une fois, ensuite tes prompts peuvent faire 10 mots et produire un travail de qualité.

Le prompt qui débloque (template)

Pour chaque nouvelle tâche Cowork, démarre avec ce template. Il oblige Claude à clarifier avant d'agir — et tu évites les livrables à côté de la plaque.

Je veux [MA TÂCHE] afin que [LE RÉSULTAT IDÉAL].

D'abord, lis les fichiers que je t'ai fournis en entier
avant de répondre.

Ne commence pas encore. Pose-moi plutôt 3-5 questions
de clarification pour que nous affinions ensemble l'approche.

Ne fais rien tant que nous ne sommes pas alignés.

Lance ton premier Cowork en 5 minutes

  1. Crée la structure ~/Claude-Cowork/ ci-dessus, remplis about-me.md.
  2. Dans Claude Desktop, clique sur Cowork (en haut de l'app), sélectionne le dossier ~/Claude-Cowork/.
  3. Premier prompt : « Lis about-me.md. Crée dans MODÈLES/ un fichier persona-template.md qui sera mon template réutilisable de persona marketing. Pose-moi des questions avant. »
  4. Claude pose ses questions, tu réponds, il génère, tu valides. Le fichier apparaît dans MODÈLES/. Tu l'as pour toujours.
Posture clé : tu n'es pas spectateur. Cowork te demandera des validations, parfois plusieurs fois. Lis ce qu'il propose avant de cliquer "approuver". L'agent vaut ce que tu acceptes de relire.
Étape 5

Mon workflow — outil par tâche

›

La règle d'or : outil par tâche, pas tâche par outil. Chaque IA est meilleure quelque part. Voici l'arbitrage que j'utilise.

Tâche Outil Pourquoi
Rédaction (post, brief, mail, devoir) Claude Meilleur niveau d'écriture, suit ton style si tu le donnes en contexte.
Analyse, raisonnement, dissertation Claude (Opus) Raisonnement profond. Bascule sur Opus uniquement quand la tâche le mérite.
Visuel social avec texte intégré GPT Image 2 (plan ChatGPT gratuit) Le rendu de texte le plus propre du marché.
Édition photo perso (retouche, recadrage IA) Nano Banana 2 (Gemini) Intégré à Google Photos, rapide.
Vidéo courte (générée IA, motion design simple) Google Veo Référence actuelle pour la vidéo IA. Pas Claude — il ne génère pas de vidéo.
Trucs génériques rapides, recherche multi-sources Gemini Bon Google Search intégré, gratuit pour usage léger.
Analyse de docs (cours, études, PDF longs) NotebookLM Sources visibles, citations, mode podcast audio. Inclus dans Gemini.
Veille temps réel (X, news fraîches, tendances) Grok (gratuit, ponctuel) Accès direct au flux X. Pas d'abonnement nécessaire pour l'usage de base.
Mise en page d'une veille Grok Claude Tu copies la sortie Grok dans Claude, qui la met au propre.
Dev simple, scripts d'une page Claude (chat) Ça suffit, pas besoin du CLI.
Dev sérieux, multi-fichiers, repo git Claude Code Lit tout le repo, exécute les commandes, gère git. C'est un agent complet.

Exemple narratif : audit de campagne d'un concurrent

  1. Grok : "Que dit X sur les dernières campagnes de [marque] ce mois-ci ?" → liste de signaux frais.
  2. NotebookLM : tu y déposes les études citées par Grok + 2 rapports Stratégies → fiche de synthèse sourcée.
  3. Claude (Project "Audit campagnes") : tu colles la fiche NotebookLM, demandes l'audit structuré (forces / faiblesses / opportunités).
  4. GPT Image 2 (gratuit) : visuel de couverture pour le livrable, avec le titre intégré dans l'image.
  5. Cowork : tu fais générer la version finale Word/Markdown du livrable dans ton dossier.
Bonnes pratiques

Pièges & règles à connaître

Lis-les une fois, tu éviteras les frustrations de débutant et les bourdes de pro.

Quel modèle quand

Sonnet (rapide) pour 90 % de ton usage : rédaction courte, brainstorming, recherche, code simple. Opus (raisonnement profond) pour : dissertation longue, analyse stratégique, debug complexe, architecture. Si tu mets Opus partout, tu vides tes quotas en 2h.

Quotas Claude Pro

Le quota se compte en messages par fenêtre glissante de 5h, et il diffère entre Sonnet et Opus. Quand tu approches la limite, l'app t'avertit et bascule vers Sonnet auto. Astuce : ouvre une nouvelle conversation au lieu d'allonger la même — les longues conversations consomment plus.

5 règles de prompt qui marchent

  1. Contexte d'abord : qui tu es, ce que tu fais, pour qui c'est.
  2. Exemples > consignes abstraites : "comme ce post X" plutôt que "ton percutant".
  3. Demande explicitement le format : "réponds en 5 bullets max" ou "en tableau".
  4. Itère, ne cherche pas la perfection au 1er coup. 3 allers-retours valent mieux qu'un mega-prompt.
  5. Challenge la sortie : "qu'est-ce qui pourrait être faux dans ce que tu viens de dire ?"

Hygiène données

  • Jamais dans un prompt : NDA, données clients identifiables, identifiants, mots de passe, numéros de carte.
  • Tout ce que tu colles part dans le cloud Anthropic. Computer Use voit ton écran quand il est actif — désactive-le quand tu ne l'utilises pas.
  • En stage : déclare à ton tuteur que tu utilises l'IA. C'est attendu en 2026, le cacher se voit.
  • Pour les devoirs notés sans déclaration autorisée : ne le fais pas. Pour t'entraîner ou structurer ta pensée : oui.

Vérification des chiffres

L'IA peut halluciner — sortir un chiffre crédible mais faux. Réflexe : tout chiffre cité dans un livrable pro doit avoir une source vérifiable. NotebookLM affiche les sources par défaut, Claude pas. Quand tu utilises Claude pour des stats, demande-lui explicitement les sources et vérifie-les avant de les inscrire.

Sauvegarde & persistance

  • Conversations Claude : sauvegardées sur ton compte, sync cloud. Visibles sur tous tes devices.
  • Projects : pareil, plus les fichiers de contexte que tu y déposes.
  • Fichiers Cowork : ils vivent sur ton disque, dans le dossier que tu lui as donné. Si tu l'effaces, c'est perdu — comme tout fichier local.
  • Conseil : pour les projets sérieux, mets le dossier Cowork sous git (même un repo perso GitHub). Tu auras l'historique gratis.

Claude dans Excel

Une IA intégrée à ton tableur. Claude lit chaque onglet, comprend les formules, sait ce que D14 contient réellement. Très utile pour reportings, suivis de campagne, analyses de données de cours.

Installer

  1. Dans Excel : Insérer → Obtenir des compléments.
  2. Recherche "Claude by Anthropic" → Ajouter.
  3. Connecte-toi avec ton compte Claude Pro.

Premiers prompts à tester

  • « Donne-moi un résumé de chaque onglet de ce classeur. »
  • « Explique en français simple ce que fait la formule en B12. »
  • « Trouve toutes les erreurs #REF! et #VALEUR! dans ce classeur, propose-moi des corrections. »
